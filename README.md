# B站游戏中心活动自动化工具

一个本地运行的管理工具，用于抓取 B站游戏中心活动、解析活动任务，并按配置执行任务和抽奖。

## 功能

- 管理多个 B站账户，并验证 Cookie 有效性
- 抓取当前活动列表，解析 Era 活动中的任务和抽奖配置
- 执行任务，包括进度上报、关注、预约、分享和浏览等类型
- 执行抽奖并保存抽奖与中奖记录
- 支持独立执行、任务后抽奖和全顺序执行三种调度模式
- 支持活动抓取、活动解析、任务和抽奖的定时调度

## 环境要求

- Node.js 18 或更高版本

## 安装与启动

```bash
npm install
npm start
```

服务默认运行在 `http://localhost:2333`。如需指定端口：

```bash
# Windows PowerShell
$env:PORT=3000; npm start

# macOS / Linux
PORT=3000 npm start
```

开发时可使用文件监听模式：

```bash
npm run dev
```

## 使用流程

1. 打开管理面板，在“账户管理”中添加账户名称和有效的 B站 Cookie。
2. 在“活动管理”中抓取活动列表，再解析需要执行的活动。
3. 在“任务执行”中选择活动和账户执行任务，或使用调度器自动执行。
4. 在“抽奖管理”中执行抽奖，或创建定时抽奖计划。
5. 在仪表盘、任务记录和中奖记录中查看执行结果。

## 调度模式

| 模式 | 行为 |
| --- | --- |
| 独立执行 | 定时任务和抽奖分别执行 |
| 组合执行 | 完成任务后立即执行抽奖 |
| 全顺序执行 | 依次处理活动和账户，按“任务 -> 抽奖”完成全流程 |

默认任务时间可在管理面板的“调度器”中修改：活动抓取为每小时整点，活动解析为每 30 分钟，任务执行为每小时第 15 分钟，独立模式下自动抽奖为每两小时一次。

## 数据存储

运行数据保存在 `data/bili-game.db`，包括账户、活动、任务记录、抽奖记录、计划和日志。备份该文件即可备份本地数据；删除该文件会清空所有数据，并在下次启动时创建新的空数据库。

Cookie 属于敏感凭据，请妥善保管 `data/bili-game.db`，不要提交或分享给他人。

## 注意事项

请仅使用自己有权操作的账户，并遵守 B站的服务规则、活动规则及适用法律。活动页面结构或接口发生变化时，部分活动可能无法解析或执行。
